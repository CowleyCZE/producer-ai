# 🔥 **CORE (musí být, jinak to nebude fungovat dobře)**

## 1. 🎯 Scoring systém (0–100 pro každý řádek)

👉 AI + backend hodnotí kvalitu

### Co hodnotit:

* rytmus (flow)
* rýmy
* přirozenost
* síla sdělení

```js
score = 
  rhythm * 0.3 +
  rhyme * 0.3 +
  natural * 0.2 +
  impact * 0.2;
```

👉 výstup:

```json
{
  "score": 72,
  "issues": ["slabý rým", "neplynulý rytmus"]
}
```
